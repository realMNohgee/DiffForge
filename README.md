# DiffForge 🔍

**Semantic diff for agent outputs across prompt versions.** Compare two outputs and see what changed — facts gained/lost, sentiment shift, overlap, length delta.

> Part of the **Agentic Reliability Suite**.

## Install
```bash
git clone git@github.com:realMNohgee/diffforge.git
cd diffforge
python3 diffforge.py --help
```

## Quick start
```bash
python3 diffforge.py --a output_v1.txt --b output_v2.txt
```
